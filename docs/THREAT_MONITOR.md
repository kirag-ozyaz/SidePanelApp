# Мониторинг внимания к АРМ

Функция в **V5** и **V6**: пятое кольцо на боковой панели — **кто подключился / лезет / долбит вход**. Это самоинформирование на рабочей станции, не SIEM.

В **V6** сбор вынесен в `ThreatBackgroundService` (фоновые задачи + `EventLogWatcher`); UI только читает последний снимок.

## UI

### `ThreatRingIndicator`

Три дуги по 120°:

1. **Удалёнка** — RDP, VNC, AnyDesk (порты, процессы).
2. **SMB** — сессии к шарам, входящий 445.
3. **Попытки** — неудачные входы (4625), агрегаты по IP.

Цвет: `Ok` → `Watch` → `Alert`. **Клик** открывает `ThreatDetailPopup` со списком `ThreatItem` (время, учётка, источник, описание, инструмент).

### Модель

```
ThreatLevel: Ok | Watch | Alert
ThreatSnapshot: Remote, Smb, Probe; OverallLevel = max(каналы)
```

## Каналы сбора

### Удалёнка

| Источник | Данные |
|----------|--------|
| WTS | Сессии, пользователь, IP клиента RDP |
| TCP inbound | 3389, 5900–5910, процессы AnyDesk/TeamViewer |
| Журнал | 4624 (type 10), 1149 — при доступе |

### SMB

| Источник | Данные |
|----------|--------|
| `NetSessionEnum` | Учётка, клиент (часто нужен админ) |
| TCP :445 | IP |
| 5140 | При включённом аудите |

### Попытки

| Источник | Данные |
|----------|--------|
| 4625 | Неудачный вход |
| Агрегация | ≥ K с одного IP за T минут |
| Firewall log | Опционально |

Пассивное сканирование без ответа ОС обычно **не видно** — только попытки входа и входящие соединения.

## Настройки (`Properties/Settings`)

| Параметр | Назначение |
|----------|------------|
| `TrustedAccounts` | Учётки через `;` |
| `TrustedRemoteIPs` | Доверенные IP для RDP |
| `FailedLogonThreshold` | K для 4625 (по умолчанию 5) |
| `FailedLogonWindowMinutes` | Окно T (по умолчанию 5) |
| `ThreatPollIntervalMs` | Интервал опроса (по умолчанию 3000) |

Также: `AutoStartPanel`, `ShowPanel`, `AllowPanelMove` (как в V4).

## Права

- WTS / TCP — обычно без админа.
- Security (4624/4625/5140) — может быть запрещён; канал помечается как ограниченный.
- `NetSessionEnum` — часто только администратор.

## Поток данных (V6)

```
ThreatBackgroundService (фон)
  ├── параллельно: Remote / Smb / Probe probes
  ├── EventLogWatcher (4624, 4625, …)
  └── снимок → GetLatestSnapshot()

OverlayPanelV6 (UI, ~1 с) → ThreatRingIndicator
  click → ThreatDetailPopup
```

Код: `SidePanelApp.V6/Security/`, контролы в `Controls/`.

## Ограничения

- Нет записи экрана RDP, нет блокировки портов — только индикация.
- При port scan часто виден только IP/порт, не «имя человека».

## Связь с окном Connections (V6)

Панель даёт **агрегированный сигнал** на краю экрана. Подробная таблица TCP/UDP, процессы и пакеты — в [CONNECTIONS.md](./CONNECTIONS.md).
